# Welcome to -KR Website

This repository hosts the code for the amazing -KR website, fully hosted using GitHub Pages. It features:

- **HTML**: Basic structure for the website.
- **CSS**: Stylish and responsive design.
- **JavaScript**: Interactive features.

### How to enable GitHub Pages
1. Go to the repository's **Settings**.
2. Navigate to the **Pages** section.
3. Choose the branch (e.g., `main`) as the source.
4. Save the settings.

Once enabled, you can access the live website at:
```
https://ruiz-2008.github.io/-KR/
```

Enjoy!
